# CVRP Heuristics vs Machine Learning: Benchmarking Tradeoffs

This repository supports ongoing research on the Capacitated Vehicle Routing Problem (CVRP), focused on modeling classical CVRP heuristics and benchmarking them against modern machine-learning-based approaches.

## Funding

This research is funded by Marco Antonio Firebaugh Scholars at UC Berkeley.

## Research Focus

- Build and analyze baseline CVRP heuristic methods.
- Compare solution quality, runtime, and scalability against ML-oriented solvers.
- Use established CVRP benchmark sets and prior literature to ground empirical comparisons.
