# Models

This directory implements heuristic approaches for the Vehicle Routing Problem (VRP), following the taxonomy proposed in:

> Liu, F., Lu, C., Gui, L., Zhang, Q., Tong, X., & Yuan, M. (2023). *Heuristics for Vehicle Routing Problem: A Survey and Recent Advances*. arXiv. [https://doi.org/10.48550/arXiv.2303.04147](https://doi.org/10.48550/arXiv.2303.04147)

## Implemented Methods

### Constructive Heuristics

* Nearest Neighbor
* Insertion
* Savings
* Sweep

### Improvement Heuristics

* 2-opt / 3-opt
* Relocate
* Exchange / Swap
* 2-opt*

### Metaheuristics

* Iterated Local Search
* Large Neighborhood Search
* Simulated Annealing
* Genetic Algorithm
* Ant Colony Optimization

These models provide both initial solution construction and iterative refinement strategies for VRP instances.
